PHASE 1의 **임시/제한 사항**

- 모든 그래픽은 절차적 생성(교체 가능 구조). 손그림 아트는 아님.
- 퀵슬롯·인벤토리·스킬·퀘스트·월드맵 버튼은 자리만 있고 잠금 상태.
- 채팅은 로컬 전용, 슬래시 명령은 개발용(PHASE 6에서 서버 권한 검사).
- HP/MP/EXP는 실제 능력치 모델 값이지만 아직 변하지 않음(전투 없음).
- 월드 변경 저장 없음, 청크 데이터는 생성 후 메모리에 상주(렌더링만 스트리밍).
- 사운드 없음.
