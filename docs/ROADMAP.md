PHASE 1의 **임시/제한 사항**

- 모든 그래픽은 절차적 생성(교체 가능 구조). 손그림 아트는 아님.
- 퀵슬롯·인벤토리·스킬·퀘스트·월드맵 버튼은 자리만 있고 잠금 상태.
- 채팅은 로컬 전용, 슬래시 명령은 개발용(PHASE 6에서 서버 권한 검사).
- (PHASE 3에서 해결) HP/MP/EXP가 변하지 않음 → 전투·레벨업 구현.
- (PHASE 2에서 해결) 월드 변경 저장 없음 → IndexedDB 저장·청크 언로드 구현.
- 사운드 없음.

PHASE 2에서 **의도적으로 미룬 것** (이유)

- 바이옴 추가(사막·설원 등): 타일/배경/식생 아트 세트가 바이옴마다 필요 → PHASE 2.5 또는 3과 병행.
- 액체(물·용암): 셀 시뮬레이션·렌더링·조명 상호작용이 커서 별도 작업 단위로 분리.

PHASE 3에서 **의도적으로 미룬 것** (이유)

- 장비 강화·무작위 옵션: 아이템 개별 데이터(인스턴스)가 필요해 인벤토리 구조 확장과 함께 진행(PHASE 5 거래와 연계).
- 장비 외형 표시(갑옷을 입으면 캐릭터 그림이 바뀜): 캐릭터 합성기에 장비 레이어가 필요 — 별도 아트 작업.
- 2차 전직·추가 직업: 데이터 구조(`advancesFrom`)는 준비됨, 콘텐츠는 후속.
- NPC·퀘스트·상점(골드): 살아있는 세계(PHASE 5)와 함께.
- 사운드(타격음·스킬음): 오디오 시스템이 아직 없음.
- 몬스터 아트는 절차적 생성(교체 가능한 아틀라스 규약) — 손그림 교체는 아트 파이프라인 단계에서.
